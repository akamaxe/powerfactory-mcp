# PowerFactory workspace

Power system studies in DIgSILENT PowerFactory, carried out by Claude Code with the `powerfactory` MCP
server. Before working, load the `powerfactory` skill: it has the verified enumerations, the result variables
and the pitfalls.

## Tools
- **PowerFactory**: the installation path and the Python API are in `powerfactory-mcp.toml` (`[powerfactory]`).
- **MCP `powerfactory`**: installed by `install.py` from the `powerfactory-mcp` repository.
  - Configuration: `powerfactory-mcp.toml`, referenced by the `PF_MCP_CONFIG` variable. After editing it,
    reconnect with `/mcp`.
  - The server launches a **worker process** that hosts the engine (`GetApplicationExt`). It restarts on its own if
    it dies or a timeout expires, and is released after 20 min of inactivity.
  - Worker log: `logs\worker.log`. Change log of edits: `logs\changes.jsonl`.
  - Test harness without MCP: `<server python> -I -m powerfactory_mcp.dev --mode parallel --op status`.

## Connection modes
- **exclusive** (default): works on the real database.
  - Changes persist and the user's GUI must be closed (otherwise ExitError 4002).
  - Before editing, use `export_project()`, which saves a .pfd backup to `backups\`.
- **parallel**: `/inMemory`, an in-memory copy of the database that coexists with the open GUI.
  - Everything is lost on disconnect, except what is exported to .pfd.
  - **Use it for exploring, for destructive tests and when the user has the GUI open.**
- The window shown by `show_gui` is read-only ([NON-INTERACTIVE MODE]).

## Folders
- `projects\` — working .pfd files.
- `results\<project>\` — tool outputs (CSV, XLSX, PNG) with a date prefix.
- `backups\` — .pfd files from `export_project`.
- `scripts\` — reusable Python or DPL scripts.
- `_ref\` — text references, searchable with Grep (generated by `python -I -m powerfactory_mcp.setup_ref`):
  - `PythonReference_en.txt` and `DplReference_en.txt`.
  - `ErrorCodeReference_en.txt`.
  - `pf_attributes.tsv`: input attributes of every class, extracted from `datascheme.db`.
- `logs\` — worker log and change log of edits.

## Conventions
- Typed tools **restore** the study case's command settings when they finish.
- Auxiliary objects carry the `MCP` prefix: `MCP N-1`, `MCP Events`, `MCP Results`, `MCP Harmonics`
  and `MCP Sweep` in the study case. There is also the `\<user>\_mcp_tmp` folder. They are reusable and can
  be safely deleted.
- Do not leave test changes in other people's projects: test in parallel mode or revert with the `old` values
  returned by `set_attributes`.
